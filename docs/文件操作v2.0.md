## POST 获取指定路径下的文件夹内容

POST /file/list

分页查询指定路径下的文件列表。

> Body 请求参数

```json
{
  "path": "/etc/",
  "page": 2,
  "pageSize": 10
}
```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|body|body|object| 是 |none|
|» path|body|string| 是 |目标路径|
|» page|body|integer| 否 |页码，默认1，如果page和pageSize都为0表示获取全部|
|» pageSize|body|integer| 否 |每页数量，默认20，如果page和pageSize都为0表示获取全部|

## GET 读取文本文件

GET /file/read/{path}

1.对于文本文件，正常返回
2.对于二进制，报错返回
3.对于<=1MB,直接返回
4.对于<=10MB,前端先弹出告警：是否确认打开，直接返回
5.对于>10MB,报错返回，前端应提示下载打开而不是使用网页编辑器
