## POST 创建凭证

POST /config/apikey

功能：新增一个 API Key 配置。
输入参数：name, provider, apiKey, baseUrl (可选), isActive, description 等。
输出字段：创建成功后的对象（包含 credentialId 和 maskedKey，不返回完整 apiKey）。

> Body 请求参数

```json
{
  "name": "string",
  "provider": "OpenAI",
  "baseUrl": "string",
  "isActive": true,
  "description": "string",
  "quotaLimit": 0,
  "apiKey": "string"
}
```

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|body|body|object| 是 |none|
|» name|body|string| 否 |凭证别名|
|» provider|body|string| 否 |服务商类型|
|» baseUrl|body|string| 否 |自定义请求地址|
|» isActive|body|boolean| 否 |是否启用|
|» description|body|string| 否 |备注说明|
|» quotaLimit|body|integer| 否 |预算额度限制，0表示没有|
|» apiKey|body|string| 是 |完整的API Key|

#### 枚举值

|属性|值|
|---|---|
|» provider|OpenAI|
|» provider|Azure|
|» provider|Anthropic|
|» provider|Custom|

> 返回示例

> 200 Response

```json
{
  "code": 1,
  "msg": "success",
  "data": {
    "name": "apiKey1",
    "provider": "Custom",
    "baseUrl": "https://both-hello.com/",
    "isActive": true,
    "description": "六效西头我重地在步。快历取好见值龙圆造产。重器部机确周。点素事却者近。",
    "quotaLimit": 69,

    "maskedKey": "sk-*********************************************312",
    "usedQuota": 0,
    "expireAt": null,
    "lastUsedAt": null,
    "createTime": "2026-04-19T16:07:36.562958",
    "updateTime": "2026-04-19T16:07:36.562965"
  }
}
```

### 返回结果

## DELETE 删除凭证

DELETE /config/apikey/{credentialId}

删除 Key
输入参数：credentialId (Path 参数)。

### 请求参数

|名称|位置|类型|必选|说明|
|---|---|---|---|---|
|credentialId|path|integer| 是 |none|

> 返回示例

```json
{
  "code": 1,
  "msg": "success",
  "data": null
}
```

```json
{
  "code": 0,
  "msg": "删除失败，不存在id为9999999999的apikey项",
  "data": null
}
```

### 返回结果

|状态码|状态码含义|说明|数据模型|
|---|---|---|---|
|200|[OK](https://tools.ietf.org/html/rfc7231#section-6.3.1)|none|Inline|

### 返回数据结构

状态码 **200**

|名称|类型|必选|约束|中文名|说明|
|---|---|---|---|---|---|
|» code|integer|true|none||none|
|» msg|string|true|none||none|
|» data|null|true|none||none|

## GET 验证凭证有效性

GET /config/apikey/check

功能：后端发起一个简单的测试请求（如查询模型列表），验证 Key 是否可用。
输入参数：credentialId。
后端直接在code里面体现，使用布尔语义

> 返回示例

> 200 Response

```json
{}
```
